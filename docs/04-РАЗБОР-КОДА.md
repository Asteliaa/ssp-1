## ProducerConsumer.cs

Три поля задают общий буфер и синхронизацию:

```csharp
private static Queue<int> _buffer = new Queue<int>();
private static SemaphoreSlim _emptySlots = null!;
private static SemaphoreSlim _filledSlots = null!;
// Мьютекс для защиты доступа к буферу
private static Mutex _mutex = new Mutex();
// Флаг остановки потоков
private static bool _isRunning = true;
```

- `Queue<int> _buffer` – очередь (первым пришёл – первым вышел).
- `_emptySlots = new SemaphoreSlim(bufferSize, bufferSize)` – сначала все места свободны: начальный счётчик `bufferSize`, максимум `bufferSize`.
- `_filledSlots = new SemaphoreSlim(0, bufferSize)` – сначала занятых мест нет.
- `Mutex _mutex` – защищает очередь.
- `_isRunning` – флаг остановки; главный поток через 5 секунд ставит `false`.

Производитель:

```csharp
static async Task Producer(int id)
{
    Random rand = new Random(id);
    while (_isRunning)
    {
        // Ждем, пока освободится место в буфере (с тайм-аутом, чтобы после остановки поток мог завершиться)
        if (!await _emptySlots.WaitAsync(500)) continue;
        // Захватываем мьютекс для безопасной работы с буфером
        _mutex.WaitOne();
        try
        {
            int item = rand.Next(1, 100);
            _buffer.Enqueue(item);
            Console.WriteLine($"[Producer {id}] Добавлен элемент: {item}. В буфере: {_buffer.Count} элементов.");
        }
        finally
        {
            _mutex.ReleaseMutex();
        }
        // Увеличиваем счетчик занятых мест
        _filledSlots.Release();
        // Имитация времени на производство
        await Task.Delay(rand.Next(200, 600));
    }
    Console.WriteLine($"[Producer {id}] Завершен.");
}
```

- `async Task` + `await` – метод может «отпустить» поток, пока ждёт, и продолжить позже на любом потоке пула.
- `await _emptySlots.WaitAsync(500)` – ждать свободное место до 500 мс; вернёт `false` по тайм-ауту (**наша правка**, чтобы поток мог завершиться).
- `_mutex.WaitOne()` … `finally { _mutex.ReleaseMutex(); }` – вход и гарантированный выход из критической секции, даже если внутри произойдёт ошибка.
- `_filledSlots.Release()` – «сообщить» потребителям, что появился элемент.
- `await Task.Delay(...)` – имитация времени производства, не занимая поток.

Потребитель устроен симметрично (`_filledSlots` ждёт, `_emptySlots` освобождает).

## DeadlockDemo.cs

```csharp
static void Thread1()
{
    lock (_lockA)
    {
        Console.WriteLine("Thread1: захватил lockA");
        Thread.Sleep(1000); // Имитация работы
        lock (_lockB)
        {
            Console.WriteLine("Thread1: захватил lockB");
        }
    }
}

static void Thread2()
{
    lock (_lockB)
    {
        Console.WriteLine("Thread2: захватил lockB");
        Thread.Sleep(1000); // Имитация работы
        lock (_lockA)
        {
            Console.WriteLine("Thread2: захватил lockA");
        }
    }
}

```

- `lock (_lockA) { ... lock (_lockB) { ... } }` – вложенные блокировки, поток держит A и ждёт B.
- `Thread.Sleep(1000)` – пауза, чтобы **оба** потока успели взять по первой блокировке (иначе deadlock случится не всегда).
- `Task.WaitAll(task1, task2)` – главный поток ждёт обе задачи; на нём программа и «висит».

Исправление `Thread2Fixed` – та же последовательность, что у `Thread1` (сначала `_lockA`, потом `_lockB`).

Тайм-аут:

```csharp
static void TakeBoth(string name, object first, string firstName, object second, string secondName)
{
    if (!Monitor.TryEnter(first, TimeSpan.FromSeconds(3)))
    {
        Console.WriteLine($"{name}: не удалось захватить {firstName} за 3 секунды");
        return;
    }
    try
    {
        Console.WriteLine($"{name}: захватил {firstName}");
        Thread.Sleep(1000); // Имитация работы
        if (Monitor.TryEnter(second, TimeSpan.FromSeconds(3)))
        {
            try { Console.WriteLine($"{name}: захватил {secondName}"); }
            finally { Monitor.Exit(second); }
        }
        else
        {
            Console.WriteLine($"{name}: не удалось захватить {secondName} за 3 секунды – возможен deadlock");
        }
    }
    finally
    {
        Monitor.Exit(first);
    }
}
```

- `Monitor.TryEnter(объект, TimeSpan)` – попытаться войти в блокировку, не дольше указанного времени; `true` – получилось.
- Вложенные `try/finally` и `Monitor.Exit` вручную освобождают то, что получено (оператор `lock` делает это сам).
- Порядок захвата оставлен **разным** (A→B и B→A), чтобы deadlock возник и был обнаружен по тайм-ауту.

## MutexCrossProcess.cs

```csharp
    public static void Run()
    {
        using (Mutex mutex = new Mutex(false, "Global\\MyAppMutex"))
        {
            Console.WriteLine("Попытка захвата глобального мьютекса...");
            if (mutex.WaitOne(TimeSpan.FromSeconds(3)))
            {
                try
                {
                    Console.WriteLine("Мьютекс захвачен. Программа выполняется.");
                    Console.WriteLine("Нажмите Enter для освобождения мьютекса...");
                    Console.ReadLine();
                }
                finally
                {
                    mutex.ReleaseMutex();
                    Console.WriteLine("Мьютекс освобожден.");
                }
            }
            else
            {
                Console.WriteLine("Не удалось захватить мьютекс (возможно, уже запущен другой экземпляр).");
            }
        }
    }
}
```

- `new Mutex(false, "Global\\MyAppMutex")` – `false`: «я не владею им сразу»; имя делает мьютекс общим для процессов.
- `mutex.WaitOne(TimeSpan.FromSeconds(3))` – ждать до 3 секунд, `false`, если не удалось.
- `using (...)` – мьютекс освобождается и закрывается автоматически.

```csharp
// Условие, затратное по времени: проверка числа на простоту делением
static bool IsPrime(int n)
{
    if (n < 2) return false;
    for (int d = 2; (long)d * d <= n; d++)
        if (n % d == 0) return false;
    return true;
}

// Пользовательские условия фильтрации
static readonly (string Name, Func<int, bool> Condition)[] Conditions =
{
    ("значение > 500000 и кратно 7", x => x > 500000 && x % 7 == 0),
    ("значение простое", IsPrime),
};
```

- Кортеж `(string Name, Func<int, bool> Condition)` хранит название условия и сам делегат.
- `x => x > 500000 && x % 7 == 0` – лямбда-условие; `IsPrime` передаётся как метод (группа методов).
